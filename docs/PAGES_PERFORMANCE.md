# Pages 加载优化验收

## 当前修正：恢复预加载

根据重复打开变慢的反馈，恢复 App 代码、剧情 JSON、图标与照片的 Service Worker 预缓存。第一次打开后后台下载，完成后再次打开使用本地缓存；音视频仍按点击下载。未进入预缓存的图片采用先显示缓存、后台更新策略，图片 HTTP 缓存时间改为一小时。保留原图压缩与后台更新优化。以下为上一轮记录，预缓存数量和上线状态不再代表当前修正版本。


目标分支：`feat/phone-a-phase1`；本地优化分支：`perf/pages-loading`。

## 完成的处理

- PWA 首次预缓存只保留入口 HTML、入口 JS/CSS 和图标，不下载整套照片、作品 JSON、其他 App 的代码。其他 App 保留现有动态导入结构。
- 音视频入口统一使用 `preload="none"`；音乐主播放器原已按点击加载并支持离开音乐 App 后继续播放，保持该行为。
- 图片异步解码，音乐列表封面延迟加载；照片详情及锁屏保持即时显示。
- 构建时自动压缩部署副本，保留原文件名及原始图片。JPEG 使用质量 82；普通图片最大宽 1920，Safari 文档图片最大宽 1600，保留长图高度比例；动画跳过。编码变大则保留原文件。
- `_headers` 对同名页面、剧情、媒体启用重新验证，对带内容哈希的 Vite assets 启用长期缓存；作品请求主动重新验证。
- 隐藏页面不执行剧情轮询更新，返回后按已流逝时间追赶；状态栏时钟只在分钟变化时更新。剧情推进和音乐播放逻辑保留。
- 构建检查超过 25 MiB 的单个文件并失败退出，阻止不兼容文件进入部署；部署副本排除临时传输文件。
- 清除时钟组件已有的未使用导入，使 lint 通过。

## 验证

- lint 通过。
- 113 项单元测试通过，包括新增的音视频按需加载及图片延迟加载检查。
- 剧情校验及 3 条剧情路径通过；13 Apps、229 records、55 events。
- TypeScript 与生产构建通过。
- 176 张部署图片优化，39.57 → 17.94 MiB，约减少 55%。原始照片未修改。
- 预缓存为 7 个条目、993.48 KiB；不包含图片集合、音视频、剧情 JSON。
- 本地 40 个并发读取客户端、共 120 次静态读取全部成功；MP3 1024 字节范围读取返回 206。

本地并发读取仅证明构建文件可被并行读取，不代表 Cloudflare 线上容量、真实浏览器人数或中国大陆网络可达性。Cloudflare 特定响应头需上线后检查，本地 Vite 不解析 `_headers`。

浏览器端回归未完成：环境无法取得有效 Chromium 下载包。未验证真机 Safari、实际点击到播放的网络时序、Service Worker 旧版本升级，以及移动网络下的加载体验。媒体和剧情不再被整站预下载，不能保证离线打开全部内容。

## 上线步骤

本次未修改剧情、原始媒体、存档格式或用户数据。未推送、未公开新增媒体、未修改线上站点。

确认公开范围后，将优化提交合入 `feat/phone-a-phase1`，在 Cloudflare Pages 当前项目使用同一分支构建；若使用本地直传，可在已登录 Cloudflare 的环境运行 `npm run deploy:pages`。该命令会重新构建并上传整个 dist，其中包含项目现有公开媒体，应确认这些媒体仍在发布范围内。

上线验收：检查首页及 work.json 的 Cache-Control；检查带哈希 JS 的一年缓存；使用新浏览器确认未打开相册或音乐时不下载整个媒体库；检查锁屏解锁、音乐播放、相册、剧情及刷新恢复；旧访客需重新打开网页以获取新版 Service Worker。
